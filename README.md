# Node.js Learning Journey

This repository is a personal study archive for learning Node.js from the ground up.
It documents the progression from JavaScript fundamentals into the Node.js runtime and core concepts.

## Learning Progression

1. JavaScript Basics
   - Variables, constants, data types, operators, primitive and non-primitive values
2. JavaScript Execution Model
   - How JavaScript runs in the runtime and memory model
3. Node.js Foundations
   - What Node.js is, how it differs from browser JavaScript, and its runtime model
